# Children's Maths Learning Apps

Interactive Reveal.js presentations for primary school mathematics.

## Files

| File | Topic | Levels |
|---|---|---|
| `times.html` | Multiplication tables 2×–20× | Lesson + practice per table, mixed quiz |
| `clock.html` | Telling time | 14 slides: hour, minute hands, o'clock, half/quarter, 5× table connection, practice |
| `add-subtract.html` | Addition & Subtraction | 8 levels: 2/3/4-digit with carry/borrow, mixed quiz |
| `multiply.html` | Multiplication | 6 levels: facts 1–9×, 2×1, 3×1, 2×2, mixed quiz |

## Usage

Open any `.html` file in a browser. Navigate with arrow keys or on-screen controls. Each level includes a lesson/example followed by a multiple-choice quiz with score tracking.
