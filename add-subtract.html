What Is Addition?

Putting Together
3 + 4 means 3 and 4 make 7
Counting Up
5 + 3 = start at 5, count 3 more → 8
Column Method
Line up H T U, add each column, carry if ≥ 10
We use the column method — always start from the Units column!

What Is Subtraction?

Taking Away
7 − 3 means take 3 from 7, leaves 4
Counting Back
9 − 4 = start at 9, count back 4 → 5
Borrowing
If top digit is smaller, borrow 1 from the next column
We call it "borrow and pay back" — always start from Units!
